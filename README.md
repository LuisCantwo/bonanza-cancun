# Bonanza Cancún

Dashboard de condiciones para paddle board (SUP) y nado en aguas abiertas en Cancún.

**Ver en vivo:** https://luiscantwo.github.io/bonanza-cancun/

- Consenso ponderado multi-modelo: viento ECMWF · ICON · GFS · MET Norway; oleaje ECMWF-WAM · MFWAM · GFS-Wave (vía Open-Meteo y api.met.no, consultados en vivo por el navegador).
- Score de bonanza 0–100 por hora, semáforo de amaneceres a 8 días, índice de claridad del agua, marea y radar de ventanas.
- Referencia local: [Windguru Cancún (spot 197679)](https://www.windguru.cz/197679).

Página 100% estática: no requiere servidor ni claves; los datos se actualizan cada vez que se abre.
